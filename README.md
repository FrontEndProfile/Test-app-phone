# AntiSocial

Personal social-media limiter for Android (Infinix Zero 30). Fully offline — no internet permission, no accounts, no data leaves the phone.

- Har app ki apni daily limit
- Limit khatam → "Bas." block screen
- Extra waqt sirf 6-digit coupon se (10 / 30 / 60 min, har coupon ek dafa)
- Limit barhana, app hatana, nayi coupon book: 2 ghante ka wait
- Aaj aur pichle 7 din ka waqt
